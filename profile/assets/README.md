# Lapser profile artwork

The wordmark SVGs are copies of Lapser's canonical brand artwork. The light and dark profile banners preserve that artwork with uniform scaling and add a decorative abstract track motif. The motif does not depict a venue or product feature. Photography is not used.

The public profile uses the supplied light/dark banners with descriptive alt text. Preserve the logo's proportions and clear space when reusing it.

`lapser-org-avatar.png` is the brand-specified 800×800 export of `lapser-org-avatar-source.svg`, the canonical social-avatar source. Upload the PNG under organisation Settings → General → Profile picture → Upload new picture. Preparing the file does not change the GitHub icon.
